Challenge A02

Intelligent Priority Engine

Transparent, explainable triage scoring calculated deterministically from seven empirical factors:

  • Immediate threat to life: Automatic critical priority boost.
  • Trapped & injured counts: Scaled casualty weighting.
  • Vulnerability indicators: Prioritization for infants, elderly, and mobility limitations.
  • Dynamic delay penalty: Escalates priority for unassigned waiting emergencies.
Every incident includes an itemized, human-readable scoring explanation for dispatcher clarity.
Challenge A07

Automated Multi-Step Workflow

End-to-end resilient orchestration from initial SOS to post-incident resolution:

REPORTED TRIAGED ASSIGNED ACCEPTED RESPONDING RESOLVED

Includes automatic failover: If a responder declines or is unreachable, the system automatically checks the next eligible responder. If none are eligible, it alerts dispatch with an UNASSIGNED diagnostic log.

Concurrency-safe atomic state transitions prevent duplicate dispatch or orphan assignments.
